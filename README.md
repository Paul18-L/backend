# Café Digital - Proyecto Full Stack

#Task Manager - Examen Parcial (Desarrollo Web Full Stack)

## Descripción
Aplicación web completa para la gestión del menú de **Café Digital**. Incluye:
- API RESTful (Node.js + Express + MongoDB/Mongoose)
- Frontend en HTML/CSS/JS (Bootstrap) que consume la API
- Operaciones CRUD sobre el recurso `products`.


## Estructura del proyecto
- `backend/` : Código del servidor (API RESTful).
- `frontend/` : Cliente web (index.html, styles.css, app.js).

## Requerimientos
- Node.js v16+ (recomendado)
- NPM o Yarn
- MongoDB Atlas (o MongoDB local)

## Instalación y ejecución (Backend)
1. git clone https://github.com/Paul18-L/cafedigital
2. cd cafedigital
