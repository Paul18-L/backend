# Café Digital - Proyecto Full Stack

## Descripción
Aplicación web completa para la gestión del menú de **Café Digital**. Incluye:
- API RESTful (Node.js + Express + MongoDB/Mongoose)
- Frontend en HTML/CSS/JS (Bootstrap) que consume la API
- Operaciones CRUD sobre el recurso `products`.

## Requisitos
- Node.js 16+
- MongoDB Atlas (o MongoDB local)
- npm
